## 4. Errors and broken state

1. **Secret exposure (high):** n8n stores the full GrowFlow service_role JWT unredacted in execution data (e.g. exec 16431, `apikey` header; only `authorization` is masked). Anyone with n8n execution read access sees it. Cause: key passed via header from `$env`, not a credential. Value masked here.
2. **Vision API likely broken:** its OpenAI credential id is `openai-credential-id` ("OpenAI Account"), a template placeholder, not the real credential (`TJm1Ph1vGD2513AH`). Never executed, so unconfirmed.
3. **Telegram bot inactive** since at least 2026-05-06. The core loop (meeting notes -> Telegram digest, Daily 9 AM trigger) is therefore not running in n8n.
4. **SQL injection surface:** Calendar Sync and the bot interpolate `{{ }}` values straight into SQL (`'{{ $json.taskId }}'::uuid`, calendar_events insert with user text). Running as the owner role, this is a real risk on the bot path.
5. **Leadership Summary "Save to Supabase"** sends meeting_title, leadership_brief etc. as HTTP *headers* (duplicated) and only writes leadership_brief in the body, so meeting_title/meeting_date are never saved.
6. Audio Transcriber uses Whisper **translate**, so non-English audio comes back in English. May be intended.
7. Four workflows not MCP-enabled (Email Ingestion, Memory Maker active; Backfill, Reprocess inactive): their keys, tables and models are unaudited. To close: enable "Available in MCP" in each workflow's settings, or export JSON.
8. Webhooks have no auth (generate-summary, chat, manual-calendar-sync, growflow-vision, growflow-transcribe). `/webhook/chat` takes `user_id` from the body, so anyone can query anyone's notes.
