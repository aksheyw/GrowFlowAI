# Screenshots

Drop screenshots into this folder using the following names; the project README references them:

| Filename | What to capture |
|---|---|
| `dashboard.png` | Web app dashboard with the plant-task grid (best hero shot) |
| `task-detail.png` | A task detail page with the hero plant and inline editing |
| `meeting-note.png` | A meeting note with AI summary + extracted tasks |
| `telegram-digest.png` | Daily 9am Telegram digest with `Done / Snooze / Tomorrow` buttons |
| `mobile.png` | Android app screenshot (or PWA on phone) showing the bottom tab bar |

Recommended: 1280×800 or 16:9 for web, 9:19.5 for mobile. PNG. Compress with [tinypng.com](https://tinypng.com/) before committing.
